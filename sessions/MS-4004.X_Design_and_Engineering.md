# MS-4004.X — Design & Engineering Hands-On Lab
### Acme Bottling · Microsoft 365 Copilot

**Session:** 5 of 7 · Design & Engineering
**Audience:** Design and engineering team members who already use Copilot and want to pull
clear insight from imperfect CRM and opportunity data.
**Format:** ~60 minutes of hands-on (up to ~75 if your group goes deep), inside a
~90-minute session.
**Level:** Intermediate. We skip the basics and get straight into real Acme Bottling work.

You'll take an opportunity/CRM export — messy, like the real thing — find aging deals and
trends, force the data-quality gaps into the open, and write a leadership summary that
states what it can't prove.

> **How to use this lab:** Just read and follow along. Nothing to install, no repo to
> download, no code to save. Open the files linked below and go.

---

## What you'll be able to do

- Analyze an opportunity export for stale deals, aging, and missing statuses.
- Identify trends by segment, region, product type, or owner.
- Make Copilot flag data-quality gaps instead of quietly filling them.
- Write a leadership summary with clear findings, risks, and stated assumptions.
- Build reusable prompts for data-quality review, aging, trends, and summaries.

## Learning arc

This lab moves in one direction: **find the truth, then act on it.**

|  | **Exercise 1 — Find what's aging and what's missing** | **Exercise 2 — Turn analysis into a leadership summary** |
|---|---|---|
| **You're doing** | Reading a messy CRM export | Packaging findings for a decision |
| **Copilot's job** | Summarize, age, group, flag gaps | Draft to a structure, state its limits |
| **Your job** | Decide which trends the data can support | Decide how much confidence to claim |
| **Stakes** | Internal — only you see it | External — leadership acts on it |
| **You leave with** | An aging list and an honest gap list | A summary, a slide, and a 4-prompt library |

Every task runs the same beat: **prompt → read it critically → keep what's reusable.**
Every exercise ends the same way: **Source / Assumptions / Risk / Human check.**

# Exercise 1 — Find what's aging and what's missing (about 30 min)

**Scenario:** Leadership wants to know which opportunities are stalling and whether the
pipeline data can even be trusted. Start there.

### Task 1 — Set your analysis voice and get a clean read (8 min)

1. First, tune Copilot for this work. In **Copilot Chat** settings, add a **custom
   instruction**:

   ```
   When I analyze pipeline or CRM data: never fill in a missing value — flag it. Say how
   many rows a conclusion is based on, and tell me when a trend is too thin to trust.
   End with the assumptions you made and what I should verify.
   ```

2. Open `AcmeBottling_Opportunities.xlsx` in Excel.
3. Open **Copilot** in Excel and paste:

   ```
   Review this opportunity export. Give me a plain-English summary: total opportunities,
   how many in each Stage, and how many rows are missing a Stage, LastActivityDate, or
   EstValueUSD. List the incomplete rows by OpportunityID. Do not guess or fill in missing
   values — just flag them.
   ```

4. Note how Copilot surfaces the gaps rather than papering over them.

> **Why this matters:** You're establishing how much of this pipeline is actually
> knowable before you let anyone draw a conclusion from it.

### Task 2 — Find the aging opportunities (10 min)

1. In the same Copilot pane, paste:

   ```
   Identify the opportunities most at risk of going stale: those with the highest AgeDays
   or no recent LastActivityDate, excluding any marked Won or Lost. Show OpportunityID,
   CustomerID, Stage, AgeDays, EstValueUSD, and Owner, sorted by age. Which owner has the
   most aging deals?
   ```

2. Then make Copilot commit to a priority:

   ```
   Of these, which three would you chase first and why? Weigh estimated value against how
   long they've been silent. Say which ones you can't rank because data is missing.
   ```

### Task 3 — Spot the trends (6 min)

1. Open `AcmeBottling_Master_Reference.xlsx` to see customer segments and product categories.
2. In Copilot Chat, paste:

   ```
   Help me find trends in this pipeline. Group opportunities by customer segment (Brewery,
   Juice, Water, Kombucha, Soda, Spirits, Coffee) and by product category (Glass, PET,
   Closure). Where is value concentrated, and where are deals stalling? For each trend,
   say how many rows it's based on and note where missing data limits the analysis.
   ```

3. Read the trends and note where gaps weaken the conclusions.

### Validation checkpoint (6 min)

- **Source:** Which file(s) did Copilot use? Did it stay inside them?
- **Assumptions:** Did it fill any blank Stage or value? Did it call a trend from thin data?
- **Risk:** What goes wrong if leadership acts on a trend built on incomplete rows?
- **Human check:** Which 2–3 opportunities will you verify in the CRM before reporting?

> **Exercise 1 output:** an aging list ranked by value and silence, plus an explicit list
> of the gaps that limit what you can claim.

# Exercise 2 — Turn analysis into a leadership summary (about 30 min)

**Scenario:** Now package it. Leadership wants a short, honest read — findings, risks, and
what to fix in the data.

### Task 1 — Keep your context clean (7 min)

1. In OneDrive, create a folder named **`Acme - Pipeline Review Q3`**.
2. Save the opportunity export and reference workbook into it.
3. Work from that folder / a fresh chat so Copilot references only this review's material.

> **Why:** One folder, one clean chat per review keeps the analysis scoped and trustworthy.

### Task 2 — Draft the leadership summary in Word (9 min)

1. Open a new **Word** doc in the review folder.
2. Open **Copilot in Word** and paste:

   ```
   Write a one-page leadership summary of this pipeline review. Structure it as: Headline
   findings, Aging risk (which deals and owners), Trends by segment and product, Data-
   quality gaps that limit confidence, and Recommended actions. Keep it under 300 words,
   plain English, no filler. End with an "Assumptions & to verify" line listing the data
   gaps.
   ```

3. Review. Confirm the assumptions/data-gap line is present and honest.

### Task 3 — Build one summary slide in PowerPoint (6 min)

1. Open a new **PowerPoint** in the same folder.
2. Open **Copilot in PowerPoint** and paste:

   ```
   Create a single executive summary slide from my leadership summary: a clear headline,
   3-4 bullet findings, one line on data-quality risk, and one recommended next step.
   Tight text, no paragraphs, no stock images. Do not state a trend as fact if the summary
   labeled it uncertain.
   ```

3. Tighten to one clean slide, and check the data-quality line survived the compression.

### Task 4 — Save your prompt library (3 min)

Create a Word doc titled **"Acme Design & Engineering — Prompt Library"** and paste in the
four prompts from the [Prompt Library](#prompt-library-your-leave-behind) section below.

This is your leave-behind. Swap in next quarter's export and reuse.

### Validation checkpoint (5 min)

- **Source:** Did the summary and slide stay inside the export and reference data?
- **Assumptions:** Did Copilot state its data gaps, or imply more certainty than the data supports?
- **Risk:** What's the cost of presenting a confident trend built on missing rows?
- **Human check:** Who validates the numbers before this reaches leadership?

> **Exercise 2 output:** a one-page leadership summary, a single executive slide that
> keeps its uncertainty, and a 4-prompt library.

## Prompt Library (your leave-behind)

Save these four. Fill the `[placeholders]` each time.

**1. Data-quality review**
```
Review [SOURCE FILE]. Give me row counts by [STATUS FIELD] and list every row missing
[REQUIRED FIELDS], by [ID FIELD]. Do not guess or fill in missing values — flag them.
```

**2. Aging / stale-record analysis**
```
From [SOURCE FILE], identify the records most at risk of going stale: highest [AGE FIELD]
or no recent [ACTIVITY FIELD], excluding [CLOSED VALUES]. Show [FIELDS], sorted by age.
Then rank the top three to chase, weighing value against time silent, and say which you
can't rank because data is missing.
```

**3. Trend analysis**
```
Find trends in [SOURCE FILE]. Group by [DIMENSION 1] and [DIMENSION 2]. Where is value
concentrated and where are records stalling? For each trend, say how many rows it's based
on and where missing data limits the analysis.
```

**4. Leadership summary**
```
Write a one-page leadership summary of this review. Structure: Headline findings, Risk,
Trends, Data-quality gaps that limit confidence, Recommended actions. Under [WORD COUNT],
plain English. End with an "Assumptions & to verify" line listing the data gaps.
Findings: [PASTE]
```

## Facilitator notes

- **Data hygiene:** The clean-folder step (Ex.2 Task 1) is the teachable habit — one
  review, one folder, one clean chat.
- **Analysis reality:** The teachable moment is the "how many rows is this based on"
  instruction. Copilot will happily describe a trend drawn from three records; making it
  show the denominator is what turns a confident sentence into a checkable claim.
- **Capture agent ideas:** This group is the most likely to raise ambitious ideas — e.g.,
  "an agent that watches the pipeline and flags aging deals automatically." Capture those
  and route to **Chris Bartlow**. Don't build them here; keep this lab current-state Copilot.
- **Timing:** Fast groups can rerun the trend analysis sliced a different way (by region or
  owner) from the same dataset.
