# MS-4004.X — Marketing & Creative Hands-On Lab
### Acme Bottling · Microsoft 365 Copilot

**Audience:** Marketing and creative team members who already use Copilot and want to move
faster on briefs, copy, and pitch decks.
**Format:** ~60 minutes of hands-on (up to ~75 if your group goes deep), inside a
~90-minute session.
**Level:** Intermediate. We skip the basics and get straight into real Acme Bottling work.

You're launching Acme's new **500 mL recyclable PET bottle**. You'll use Copilot to build
a campaign brief, an executive pitch deck, and brand-safe copy — and leave with reusable
prompts.

> **How to use this lab:** Just read and follow along. Nothing to install, no repo to
> download, no code to save. Open the files linked below and go.

---

## What you'll be able to do

- Build a campaign brief from goals and proof points using Researcher.
- Draft an executive presentation from that brief.
- Write brand-safe marketing copy that stays inside approved rules.
- Build reusable prompts for briefs, content, presentations, and brand-safe reviews.
- Keep a validation habit so nothing goes out without a human check.

## Learning arc

This lab moves in one direction: **agree on the message, then build everything from it.**

|  | **Exercise 1 — From goals to a campaign brief** | **Exercise 2 — Build the executive pitch** |
|---|---|---|
| **You're doing** | Turning approved goals into a brief | Turning the brief into sales-ready assets |
| **Copilot's job** | Structure the message, hold the proof points | Draft the deck and one-pager, flag risk |
| **Your job** | Decide what's on-message and on-brand | Decide what's safe to show a customer |
| **Stakes** | Internal — only the team sees it | External — sales leadership and customers see it |
| **You leave with** | A one-page brief every claim traces back to | Two assets + a 4-prompt library |

Every task runs the same beat: **prompt → read it critically → keep what's reusable.**
Every exercise ends the same way: **Source / Assumptions / Risk / Human check.**

# Exercise 1 — From goals to a campaign brief

**Objective:** Produce a one-page campaign brief and three pieces of launch copy where
every claim traces back to an approved proof point.

**Scenario:** Leadership approved the new PET line. You have goals and proof points. Turn
them into a brief the sales and creative teams can run with.

### Task 1 — Set your brand voice and clean your context

First you'll tell Copilot how to write for marketing, then scope it to this campaign only.

1. Open **Copilot Chat** and go to **Settings** (gear icon or your profile picture, top
   right) → **Personalization**.
2. Add this **custom instruction** and save:

   ```
   When I work on marketing content: write practical, confident copy in plain English.
   No hype words, no superlatives, no invented claims. Use only the proof points I give
   you, and flag anything you're unsure about instead of guessing. End with a note on
   what a human must review for brand tone and usage rights.
   ```

   *No Personalization option in your tenant? Paste this block at the top of your first
   prompt in each exercise instead.*
3. In **OneDrive**, create a folder named **`Acme - PET500 Launch`**.
4. Save the campaign input brief, product catalog, and customers file into it.
5. In Copilot Chat, start a **New chat** (the pencil or **New chat** icon at the top of
   the pane) so nothing from other campaigns bleeds in.

> **Why:** One folder, one clean chat keeps your copy on-brand and on-message. The custom
> instruction keeps the hype out without you re-typing the rule every prompt.

### Task 2 — Build the campaign brief with Researcher

1. In **Copilot Chat**, open **Agents** in the left sidebar (or the agent picker above the
   prompt box) and select **Researcher**.
2. Attach `AcmeBottling_Campaign_Goals.md` using the paperclip icon next to the prompt box.
3. Paste this prompt and press Enter:

   ```
   Using only the attached campaign input brief, build a one-page campaign brief for
   Acme Bottling's new 500 mL recyclable PET bottle (SKU-PET500). Include: objective,
   target audience, three key messages built from the approved proof points, the featured
   customers (Sunrise Juice, Blue Ridge Springs, Prairie Kombucha), and a simple success
   metric. Practical, confident tone — no hype words. Do not invent claims beyond the
   proof points. End with an "Assumptions & to verify" line.
   ```

4. Review the result. Confirm every claim traces back to the input brief.

### Task 3 — Draft brand-safe launch copy

1. Stay in the same chat (so Copilot still has the brief in context) and paste:

   ```
   Write three short pieces of launch copy from this brief: (1) a 40-word LinkedIn post,
   (2) a two-sentence email subject + preview line, (3) a 60-word sales one-liner.
   Follow the brand rules: practical and confident, no hype words, no new claims. Use only
   the approved proof points. Flag anything you're unsure about instead of guessing.
   ```

2. Read for tone. Mark anything Copilot flagged for you to confirm.

### Validation checkpoint

- **Source:** Did Copilot use only the attached brief, or did it reach outside it?
- **Assumptions:** Any claim that isn't in the approved proof points?
- **Risk:** What happens if an unverified claim ships in a public post?
- **Human check:** Who approves brand tone and usage rights before anything goes live?

> **Exercise 1 output:** a one-page campaign brief plus three pieces of launch copy, every
> claim traceable to an approved proof point.

# Exercise 2 — Build the executive pitch

**Objective:** Turn the brief into a 6-slide pitch deck and a sales one-pager, then run a
brand-risk pass before anything leaves the team.

**Scenario:** Sales leadership wants a short deck to open PET line conversations. Build it
from your brief — fast, clean, on-brand.

### Task 1 — Draft the deck in PowerPoint

1. Open **PowerPoint**, create a new blank presentation, and save it into your
   **`Acme - PET500 Launch`** folder.
2. On the **Home** tab, click the **Copilot** button (far right of the ribbon).
3. Paste:

   ```
   Create a 6-slide executive pitch deck for Acme Bottling's new 500 mL recyclable PET
   bottle. Base it on my campaign brief. Slides: (1) title, (2) the opportunity, (3) three
   key messages, (4) proof points (18% lighter, 100% recyclable, 30% lower cost than glass),
   (5) featured customers, (6) call to action. Keep text tight — short bullets, no
   paragraphs. Do not add stock images or logos; leave image placeholders labeled
   "approved product photo here."
   ```

4. Review the flow. Note where you'll drop the approved product photo.

> **Brand-safe reminder:** Copilot may not match brand templates or images perfectly.
> That's expected — you place approved assets and review before sharing.

### Task 2 — Turn the deck into a one-pager

1. Open **Word**, create a new document, and save it into the same folder.
2. On the **Home** tab, click the **Copilot** button, then paste:

   ```
   From my campaign brief and pitch deck content, write a one-page sales enablement
   sheet for the PET500 launch: a short intro, the three key messages, the proof points as
   a tight bullet list, and a "who to call" line naming the featured customers' segments.
   Under 250 words, no hype. End with an "Assumptions & to verify" line.
   ```

3. Tighten and confirm the verify line is present.

### Task 3 — Run the brand and usage-rights pass

1. Go back to your clean **Copilot Chat**.
2. Paste both the deck outline and the one-pager text into the prompt, then add:

   ```
   Review this deck outline and one-pager against these brand rules: practical and
   confident tone, no hype words, no claims outside the approved proof points, no stock
   imagery or logos. Return a table: item, the rule it may break, and the fix. If you are
   not certain, say so rather than approving it.
   ```

3. This is a *first pass*, not an approval. A human still signs off.

### Task 4 — Save your prompt library

1. Create a new **Word** doc titled **"Acme Marketing — Prompt Library"**.
2. Paste in the four prompts from the
   [Prompt Library](#prompt-library-your-leave-behind) section below.
3. Save it somewhere you'll actually find it again.

This is your leave-behind. Swap in the next product or campaign and reuse.

### Validation checkpoint

- **Source:** Did the deck and one-pager stay inside the approved brief and proof points?
- **Assumptions:** Did Copilot add any claim, image, or logo it shouldn't have?
- **Risk:** What's the cost of shipping off-brand visuals or an unapproved claim?
- **Human check:** Who does the final brand + usage-rights review before this goes out?

> **Exercise 2 output:** a 6-slide pitch deck, a sales enablement one-pager, a brand-risk
> list, and a 4-prompt library.

## Prompt Library (your leave-behind)

Save these four. Fill the `[placeholders]` each time.

**1. Campaign brief**
```
Using only [SOURCE BRIEF], build a one-page campaign brief for [PRODUCT/SKU]. Include:
objective, target audience, three key messages built from the approved proof points,
[FEATURED CUSTOMERS], and a simple success metric. Practical, confident tone — no hype.
Do not invent claims. End with an "Assumptions & to verify" line.
```

**2. Brand-safe content**
```
Write [FORMATS AND LENGTHS] from this brief. Follow the brand rules: practical and
confident, no hype words, no new claims, approved proof points only. Flag anything you're
unsure about instead of guessing. Brief: [PASTE]
```

**3. Presentation draft**
```
Create a [N]-slide executive pitch deck for [PRODUCT], based on my campaign brief.
Slides: [LIST]. Short bullets, no paragraphs. Do not add stock images or logos; leave
placeholders labeled "approved asset here."
```

**4. Brand & usage-rights review**
```
Review the content below against these brand rules: [RULES]. Return a table: item, the
rule it may break, and the fix. If you are not certain, say so rather than approving it.
Content: [PASTE]
```

## Facilitator notes

- **Data hygiene:** The clean-folder step (Ex.1 Task 1) is the teachable habit — one
  campaign, one folder, one clean chat.
- **Brand reality:** Reinforce that Copilot won't perfectly follow brand templates or
  generate brand-safe imagery. Teach method and source control, not image generation.
  Ex.2 Task 3 is a first-pass filter, never an approval.
- **Capture agent ideas:** If someone imagines "a brand-checker that reviews every draft
  automatically," that's a real agent opportunity — capture it and route to **Chris
  Bartlow**. Keep this lab current-state Copilot.
- **Timing:** Each exercise is about half the hands-on time. Fast groups can rerun the
  brief for a second product (SKU-GB16 flint glass) from the same catalog.
